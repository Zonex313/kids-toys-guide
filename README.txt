儿童友好 3D 打印玩具导览站 — 使用说明
================================

这是一套静态网页（全中文），可离线打开，面向不太了解 3D 打印的家长。

一、如何打开
-----------
方法 A（最简单）：直接双击打开 index.html
  现已支持用浏览器「双击 / file://」打开；年龄列表与模型详情会通过配套的 .js 数据加载。

方法 B（推荐，加载更快）：双击「打开网站.bat」（Windows）或运行「打开网站.sh」（Mac/Linux）
  会启动本地服务后，用浏览器打开：http://127.0.0.1:8765/

也可手动：

  cd 到本目录（含 index.html 的文件夹）
  python3 -m http.server 8765

  然后用浏览器打开：http://127.0.0.1:8765/

二、页面说明
-----------
  index.html   首页：年龄入口、新手入口、安全总提示
  guide.html   新手完整教程（自己打印 / 代打 / 安全 / FAQ）
  age.html?band=2-3   某一岁的模型列表（搜索、分类、分页）
  model.html?id=数字&band=2-3   单个模型详情

三、数据
-----------
  data/summary.json / summary.js     总数与各年龄统计
  data/editorial.json / editorial.js 各年龄段文案
  data/age/0-1.json … 7-8.json       该年龄模型（.js 为 file:// 配套）
  说明：.json 供 http 服务 fetch；.js 写入 window.__KIDS_DATA__，供双击打开时使用。

四、重要声明
-----------
  · 模型来自 MakerWorld 公开列表；下载与授权以原页面为准
  · 本站不托管 3MF/STL 等打印文件
  · 年龄划分为整理参考；安全角标仅在确有风险时显示
  · 商用请自行核对许可证与平台规则
